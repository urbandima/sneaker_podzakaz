Модуль: `/admin/receiving` · Версия: 1.0 · Дата: 2026-04-27

| Роль | Раздел |

| Логист | §2 — статусы и расходы |

## §1. Закупщик — создание приёмки

### Когда создавать вручную?
- Плановая поставка от поставщика
- Прямая закупка без Buyout

> **Из выкупа:** Когда Buyout переходит в статус `accepted`, приёмка создаётся **автоматически** в статусе «Прибыла». Перейти к §3.

### Как создать

1. Меню → **Приёмки** → **+ Новая приёмка**
2. **Шаг 1 — Поставщик и даты:**
   - Выбрать поставщика (или оставить пустым)
   - Указать ожидаемую дату прибытия
   - Добавить примечания при необходимости
3. **Шаг 2 — Товары:**
   - Нажать «+ Добавить позицию»
   - Найти товар по названию или SKU
   - Выбрать размер (если есть)
   - Указать `qty_expected` — сколько единиц ожидается
   - Указать цену в исходной валюте и курс конвертации
   - Повторить для каждого SKU
4. **Шаг 3 — Расходы** (опционально):
   - Если известны авансовые расходы, добавить их
   - Выбрать метод распределения
5. Нажать **«Создать приёмку»**

### Что происходит автоматически
- Генерируется уникальный номер `RCV-YYYYMM-NNNNN`
- Расходы распределяются по позициям
- `final_cost_byn` = `unit_cost_byn × qty_arrived + allocated_expenses`

## §2. Логист — статусы и расходы

### Изменение статуса

Открыть приёмку → правая колонка → **«Сменить статус»** → выбрать нужный.

| Текущий | → | Следующий | Когда |
|---|---|---|---|
| Черновик | → | В пути | Поставщик подтвердил отгрузку |
| В пути | → | Прибыла | Товар получен на складе/таможне |
| Прибыла | → | Проверка | Кладовщик начал приёмку |
| Проверка | → | Принята / Частично | После подсчёта |

### Добавление расходов

После того как известны итоговые расходы (таможенные пошлины, доставка):

1. Открыть приёмку → раздел **«Расходы на поставку»**
2. Нажать **«+ Добавить расход»**
3. Выбрать тип: `Таможня`, `Доставка`, `Страховка`, `Упаковка`, `Прочее`
4. Ввести сумму и валюту (курс конвертации подставляется автоматически)
5. Выбрать **метод распределения**:
   - **Поровну** — делится равномерно между всеми позициями
   - **По количеству** — пропорционально qty_arrived
   - **По стоимости** — пропорционально unit_cost_byn × qty_arrived
6. Нажать «Добавить»

> Система **автоматически пересчитывает** `allocated_expenses_byn` и `final_cost_byn` для каждой позиции.

### Пример расчёта

Поставка: 3 товара, расходы 150 BYN:
- Таможня 100 BYN (equal) → 33.33 BYN на каждую позицию
- Доставка 50 BYN (by_qty) → пропорционально количеству

## §3. Кладовщик — физическая приёмка

### Подготовка

1. Найти приёмку в статусе **«Прибыла»**
2. Сменить статус на **«Проверка»** (кнопка в правой колонке)

### Подсчёт каждой позиции

В таблице **«Товары»**:
- Поле **«Прибыло»** — ввести фактическое количество полученных единиц
- Поле **«Дефект»** — ввести количество единиц с дефектами/повреждениями

> На складе засчитываются только `qty_arrived - qty_defected` единиц.

Нажмите Enter или Tab — данные сохраняются автоматически, итоги пересчитываются.

### Загрузка документов

Правая колонка → **«Документы»**:
- Перетащить файл в область загрузки ИЛИ нажать на неё
- Выбрать тип документа: `Инвойс`, `Таможенная декларация`, `Фотография`, `Прочее`
- Форматы: PDF, JPG, PNG, DOC, XLS

### Принятие на склад

Когда все позиции подсчитаны:

1. Нажать кнопку **«Принять на склад»** (зелёная, в шапке)
2. Подтвердить во всплывающем окне

**Что происходит автоматически:**
- `product.stock_count += qty_arrived - qty_defected` (для товаров без размеров)
- `product_size.stock += qty_arrived - qty_defected` (для товаров с размерами)
- Связанные заказы (через Buyout) → статус `ready_to_ship`
- Статус приёмки → `Принята` (если всё пришло) или `Частично` (если недостача)

### Частичная приёмка

Если `qty_arrived < qty_expected` хотя бы для одной позиции → статус `Частично`. Остаток можно оформить новой приёмкой.

## §4. Бухгалтер — расходы и документы

### Просмотр расходов

Открыть приёмку → раздел **«Расходы на поставку»** → видны все расходы с суммами в BYN.

Правая колонка → **«Итоги»**:
```
Стоимость товаров:   1 234.56 BYN
Расходы:               150.00 BYN
─────────────────────────────────
Итого с расходами:   1 384.56 BYN
```

### Загрузка и проверка документов

1. Загрузить инвойс поставщика (тип: `Инвойс`)
2. Загрузить таможенную декларацию (тип: `Таможенная декларация`)
3. Сверить суммы в документах с суммами расходов в системе
4. При расхождении — отредактировать расход (кнопка карандаша)

### Корректировка расходов

Если после загрузки документов суммы расходов отличаются:
1. Нажать **корзину** рядом с неверным расходом → удалить
2. **«+ Добавить расход»** → ввести правильную сумму
3. Система автоматически пересчитает распределение

## Частые сценарии

### Полная приёмка (всё пришло в норме)

```
Создать → добавить SKU → draft
Поставщик отгрузил → in_transit
Прибыло → arrived
Начать проверку → inspecting
Все qty_arrived = qty_expected, дефектов нет
[Принять на склад] → accepted
```

### Частичная приёмка (недостача)

```
... → inspecting
qty_arrived < qty_expected для 1+ позиций
[Принять на склад] → partial
Остаток оформить новой приёмкой
```

### Приёмка с дефектами

```
... → inspecting
qty_arrived = 5, qty_defected = 1 → на склад зачисляется 4 ед.
[Принять на склад] → accepted/partial
Дефектный товар → отдельная процедура возврата поставщику
```

### Отмена приёмки

```
Любой статус до accepted/partial
[⋯] → [Отменить] → ввести причину → cancelled
Склад НЕ обновляется
```

### Приёмка из Buyout

```
Buyout → [Принять выкуп] → status: accepted
↓ автоматически
Receiving создан со статусом arrived, товары из Buyout добавлены
→ перейти к §3 (проверка и оприходование)
```

## Статусы и переходы

```
draft ──► in_transit ──► arrived ──► inspecting ──► accepted
  │            │              │            │
  └──────────────────────────────────────► cancelled
                                           │
                                    partial (если недостача)
```

| Статус | Цвет | Финальный? |
|---|---|---|
| Черновик | серый | нет |
| В пути | оранжевый | нет |
| Прибыла | синий | нет |
| Проверка | фиолетовый | нет |
| Принята | зелёный | **да** |
| Частично | оранжево-красный | **да** |
| Отменена | красный | **да** |

## KPI на главной странице

| Метрика | Что считает |
|---|---|
| В пути | Приёмки в статусе `in_transit` |
| Прибыло / Проверка | `arrived` + `inspecting` |
| Принято в [месяц] | `accepted` + `partial` за текущий месяц |
| BYN за месяц | `total_with_expenses_byn` за текущий месяц |
