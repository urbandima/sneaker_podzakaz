## 🚨 **Проблема:**

**Ошибка:** `SQLSTATE[42S22]: Column not found: 1054 Unknown column 'is_approved' in 'where clause'`

**SQL запрос:** `SELECT * FROM product_review WHERE (is_approved=TRUE) AND (product_id=8)`

**Причина:** Код использовал поле `is_approved`, которого не существует в таблице `product_review`

---

## ✅ **Решение:**

### 1. **Анализ структуры таблицы**

**Реальные поля в `product_review`:**
```sql
| is_published | tinyint | MUL | 0 |
| is_verified  | tinyint |     | 0 |
| is_featured  | tinyint |     | 0 |
```

**Отсутствующее поле:** `is_approved`

### 2. **Исправление кода**

**Заменен `is_approved` → `is_published` в 2 файлах:**

#### 📁 `ProductRepository.php` (строка 90)
```php
// До:
$q->where(['is_approved' => true])->orderBy(['created_at' => SORT_DESC]);

// После:  
$q->where(['is_published' => true])->orderBy(['created_at' => SORT_DESC]);
```

#### 📁 `Product.php` (строка 451)
```php
// До:
->where(['is_approved' => true])

// После:
->where(['is_published' => true])
```

### ✅ **Ошибка устранена:**
- Страница товара теперь загружается без ошибок

- `is_verified` = отзыв проверен модератором  
- `is_featured` = отзыв избранный/рекомендуемый
