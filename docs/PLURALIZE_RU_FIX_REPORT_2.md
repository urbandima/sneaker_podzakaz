## 🚨 **Проблема:**

**Ошибка:** `Undefined variable $pluralizeRu` на строке 253

**Контекст:** Пользователь видит ошибку хотя функция определена

**Возможные причины:**
- Кэш браузера показывает старую версию
- Сессионный кэш Yii2
- Проблема с порядком загрузки

---

## ✅ **Решение:**

### 1. **Проверено состояние функции:**
```php
// Функция определена в начале файла (строка 11)
function pluralizeRu($number, $titles) {
    $cases = [2, 0, 1, 1, 1];
    return $titles[($number % 100 > 4 && $number % 100 < 20) ? 2 : $cases[min($number % 10, 5)]];
}
```

### 2. **Добавлены мета-теги для сброса кэша:**
```php
// Сброс кэша браузера
$this->registerMetaTag(['http-equiv' => 'Cache-Control', 'content' => 'no-cache, no-store, must-revalidate']);
$this->registerMetaTag(['pragma' => 'no-cache']);
$this->registerMetaTag(['expires' => '0']);
```
