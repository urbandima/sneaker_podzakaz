# 🔗 Отчет о связывании статусов заказов

**Дата:** 01.04.2026  
**Статус:** ✅ СТАТУСЫ ПОЛНОСТЬЮ СВЯЗАНЫ  
**Приоритет:** 🔴 КРИТИЧЕСКИЙ

---

## 🎯 **Проблема:**

Статусы заказов в настройках (`/admin/settings/statuses`) не были связаны со статусами в заказах. Это приводило к:

- Разным статусам в настройках и реальных заказах
- Невозможности управления цветами статусов
- Десинхронизации данных

---

## ✅ **Решение:**

### 1. **Синхронизация статусов в БД**

**Добавлены недостающие статусы в `order_status`:**
```sql
INSERT INTO order_status (key, label, sort, logist_available, is_active) VALUES 
('confirmed', 'Подтвержден', 10, 0, 1),
('shipped', 'Отправлен', 20, 1, 1), 
('delivered', 'Доставлен', 30, 1, 1)
```

**Результат:** Все статусы из заказов теперь есть в настройках

### 2. **Добавлено поле `color` в таблицу**

```sql
ALTER TABLE order_status ADD COLUMN color VARCHAR(20) DEFAULT 'secondary' AFTER label;
```

**Настроены цвета для статусов:**
- `created` → `info` (синий)
- `paid` → `success` (зеленый)
- `accepted` → `primary` (фиолетовый)
- `ordered` → `warning` (желтый)
- `received` → `primary` (фиолетовый)
- `issued` → `success` (зеленый)
- `confirmed` → `primary` (фиолетовый)
- `shipped` → `info` (синий)
- `delivered` → `success` (зеленый)

### 3. **Обновлен контроллер настроек**

**Добавлено сохранение цвета:**
```php
$model->color = $statusData['color'] ?? 'secondary';
```

### 4. **Обновлен интерфейс настроек**

**Теперь используются реальные цвета из БД:**
```php
$status['color'] // Вместо $status['color'] ?? $statusColors[$status['key']] ?? 'secondary'
```

---

## 📊 **Результат связывания:**

### ✅ **Единый источник статусов:**
- **Заказы:** `created`, `paid`, `confirmed`, `ordered`, `shipped`, `delivered`
- **Настройки:** те же самые статусы с возможностью управления

### ✅ **Управление цветами:**
- Цвета хранятся в БД
- Можно изменить через интерфейс настроек
- Применяются везде в админ-панели

### ✅ **Консистентность данных:**
- Статусы в заказах используют `Yii::$app->settings->getStatuses()`
- Настройки работают с той же таблицей `order_status`
- Полная синхронизация данных
