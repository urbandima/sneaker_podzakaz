# SEO 100/100 - Полный чек-лист

## Чек-лист для достижения 100/100 баллов SEO

### 1. Техническая база (20 баллов)

| Требование | Статус | Как проверить | Как исправить |
|------------|--------|---------------|---------------|
| HTTPS | ⬜ | Проверить URL (`https://`) | Установить SSL сертификат |
| Мобильная адаптивность | ⬜ | Chrome DevTools → Toggle Device Toolbar | Использовать responsive design |
| Скорость загрузки < 2.5s | ⬜ | PageSpeed Insights / GTmetrix | Оптимизировать изображения, включить кэш |
| Core Web Vitals (LCP < 2.5s) | ⬜ | Chrome DevTools → Performance | Оптимизировать Largest Contentful Paint |
| Нет 404 ошибок | ⬜ | Screaming Frog / Google Search Console | Исправить битые ссылки |

### 2. Мета-теги (15 баллов)

| Требование | Статус | Как проверить | Как исправить |
|------------|--------|---------------|---------------|
| Уникальный title (50-60 симв) | ⬜ | `document.title` в консоли | Заполнить meta_title для всех страниц |
| Уникальный description (150-160 симв) | ⬜ | `document.querySelector('meta[name="description"]')` | Заполнить meta_description |
| Canonical URL | ⬜ | `document.querySelector('link[rel="canonical"]')` | Добавить `<link rel="canonical">` |
| Robots meta tag | ⬜ | `document.querySelector('meta[name="robots"]')` | Убрать `noindex` с нужных страниц |
| Charset UTF-8 | ⬜ | Проверить `<meta charset>` | Установить `UTF-8` |

### 3. Структура сайта (15 баллов)

| Требование | Статус | Как проверить | Как исправить |
|------------|--------|---------------|---------------|
| Правильная иерархия H1-H6 | ⬜ | W3C Validator | Один H1 на страницу, логичная структура |
| ЧПУ (человеко-понятные URL) | ⬜ | Проверить URL в адресной строке | `/product/nike-air-max` вместо `?id=123` |
| Хлебные крошки | ⬜ | Наличие на странице | Добавить breadcrumb с Schema.org |
| Пагинация с rel="next/prev" | ⬜ | Проверить код пагинации | Добавить `rel="next"` и `rel="prev"` |

### 4. Контент (20 баллов)

| Требование | Статус | Как проверить | Как исправить |
|------------|--------|---------------|---------------|
| Уникальный контент | ⬜ | Copyscape / Siteliner | Написать уникальные описания |
| Оптимальная плотность ключей (1-3%) | ⬜ | SEO-анализаторы | Разбавить или добавить ключевые слова |
| ALT тексты изображений | ⬜ | `document.querySelectorAll('img:not([alt])')` | Добавить `alt="описание"` |
| Внутренние ссылки | ⬜ | Проверить перелинковку | Добавить ссылки на связанные товары |
| Структурированные данные | ⬜ | Google Rich Results Test | Добавить Schema.org JSON-LD |

### 5. Файлы и индексация (15 баллов)

| Требование | Статус | Как проверить | Как исправить |
|------------|--------|---------------|---------------|
| Sitemap.xml актуальный | ⬜ | `/sitemap.xml` в браузере | Генерировать через SEO панель |
| Robots.txt правильный | ⬜ | `/robots.txt` в браузере | Настроить в SEO панели |
| Нет дублей контента | ⬜ | `site:ваш-сайт.ru` в Google | Canonical + 301 редиректы |
| Страницы не закрыты от индекса | ⬜ | Google Search Console → Coverage | Убрать `noindex` с нужных страниц |

### 6. Open Graph и соцсети (10 баллов)

| Требование | Статус | Как проверить | Как исправить |
|------------|--------|---------------|---------------|
| og:title, og:description | ⬜ | Facebook Sharing Debugger | Добавить `<meta property="og:*">` |
| og:image (1200x630px) | ⬜ | Проверить через debugger | Добавить изображение 1200x630 |
| Twitter Cards | ⬜ | Twitter Card Validator | Добавить `twitter:*` мета-теги |
| Favicon всех форматов | ⬜ | `/favicon.ico` | Добавить favicon.ico, png, svg |

### 7. Дополнительно (5 баллов)

| Требование | Статус | Как проверить | Как исправить |
|------------|--------|---------------|---------------|
| AMP версии (для новостей) | ⬜ | Проверить `/amp/` URL | Создать AMP версии страниц |
| Мультиязычность hreflang | ⬜ | HTML код | Добавить `<link rel="alternate" hreflang>` |

## Инструменты проверки

### Бесплатные:
1. **Google PageSpeed Insights** - скорость и Core Web Vitals
2. **Google Search Console** - индексация и ошибки
3. **Google Rich Results Test** - микроразметка
4. **W3C Validator** - валидация HTML

3. **Sitebulb** - визуальный SEO аудит

## Быстрые победы (сделайте в первую очередь)

### 1. Заполнить все meta-теги
**Где:** Админка → SEO → Массовое редактирование meta-тегов

**Шаблоны для товаров:**
- **Title:** `{brand} {name} - купить в Минске | СНИКЕРХЭД`
- **Description:** `Оригинальные {brand} {name} по лучшей цене. Доставка по Минску и Беларуси. Гарантия подлинности. Закажите сейчас!`
- **Keywords:** `{brand}, {name}, купить, оригинал, Минск`

### 2. Исправить 404 ошибки
**Где:** Админка → SEO → Редиректы

Создайте 301 редиректы для:
- Удалённых товаров → на категорию
- Изменённых URL → на новый URL
- Ошибок в URL → правильный вариант

### 3. Сгенерировать sitemap.xml
**Где:** Админка → SEO → Sitemap

Нажмите "Сгенерировать" — файл создастся автоматически.

### 4. Проверить robots.txt
**Где:** Админка → SEO → Robots.txt

Убедитесь, что:
- `Disallow: /admin/` — админка закрыта
- `Allow: /` — сайт открыт
- `Sitemap: /sitemap.xml` — указан путь

### 5. Добавить ALT тексты
**Где:** Админка → Каталог → Товары → каждый товар

Заполните поле "ALT текст" для всех изображений.

## Примеры правильных meta-тегов

### Товар:
```html
<title>Nike Air Max 90 - купить в Минске | СНИКЕРХЭД</title>
<meta name="description" content="Оригинальные Nike Air Max 90 по лучшей цене. Доставка по Минску и Беларуси. Гарантия подлинности. Закажите сейчас!">
<meta name="keywords" content="Nike, Air Max 90, купить, оригинал, Минск">
<link rel="canonical" href="https://sneakerhead.by/catalog/product/nike-air-max-90">
```

### Категория:
```html
<title>Кроссовки Nike - купить оригинал | СНИКЕРХЭД</title>
<meta name="description" content="Большой выбор оригинальных кроссовок Nike. Air Max, Dunk, Jordan. Доставка по Минску и всей Беларуси.">
```

### Open Graph:
```html
<meta property="og:title" content="Nike Air Max 90 - купить в Минске">
<meta property="og:description" content="Оригинальные кроссовки Nike Air Max 90">
<meta property="og:image" content="https://sneakerhead.by/images/products/nike-air-max-90.jpg">
<meta property="og:url" content="https://sneakerhead.by/catalog/product/nike-air-max-90">
<meta property="og:type" content="product">
```
