## 🚨 **Проблема:**

**Ошибка:** `Undefined variable $pluralizeRu`

**Место:** `frontend/views/catalog/product.php` строка 247

**Код:** 
```php
echo $actualReviewsCount . ' ' . $pluralizeRu($actualReviewsCount, ['отзыв', 'отзыва', 'отзывов']);
```

**Причина:** Функция `pluralizeRu` не была определена

---

## ✅ **Решение:**

### 1. **Добавлена функция `pluralizeRu`**

```php
// Функция для склонения русских слов
function pluralizeRu($number, $titles) {
    $cases = [2, 0, 1, 1, 1];
    return $titles[($number % 100 > 4 && $number % 100 < 20) ? 2 : $cases[min($number % 10, 5)]];
}
```

### 2. **Принцип работы функции:**

- **1 отзыв** → `отзыв` (1, 21, 31...)
- **2 отзыва** → `отзыва` (2-4, 22-24, 32-34...)  
- **5 отзывов** → `отзывов` (5-20, 25-30, 35-40...)
