# Управление контентом: категории и бренды

## Изображения категорий

### Как добавить или изменить фото категории

1. Откройте `/admin/category`
2. В столбце «Фото» нажмите на текущую картинку или оранжевый бейдж «Без фото» для быстрой загрузки прямо из списка (AJAX-оверлей без перехода на другую страницу).
3. Или перейдите в редактирование: нажмите кнопку «Редактировать» (иконка карандаша) → в правой колонке «Изображение категории» выберите файл.

### Технические требования

- Рекомендуемый размер: **600×400 px**
- Форматы: JPG, PNG, WebP
- Файл сохраняется в `frontend/web/uploads/categories/`
- В базе хранится относительный путь `/uploads/categories/имя_файла.jpg`

### Что происходит если изображение отсутствует

Используется каскад замен (graceful fallback):

1. Берётся поле `category.image` — если не пустое, используется оно.
2. Если пустое — контроллер подтягивает первый товар категории (`is_active = 1`, `sort_order ASC`) и использует его `main_image_url`.
3. Если товаров нет — в landing-представлении рендерится стилизованный placeholder-div с первой буквой названия категории.

## Изображения брендов (логотип + обложка)

### Как добавить логотип бренда

1. Откройте `/admin/brand`
2. В столбце «Лого» нажмите на текущий логотип или бейдж «Без лого» для быстрой загрузки (AJAX-оверлей).
3. Или перейдите в редактирование: кнопка «Редактировать» → секция «Логотип» → выберите файл либо укажите внешний URL в поле `logo_url`.

### Как добавить обложку бренда (баннер)

1. Перейдите в редактирование бренда: `/admin/brand/{id}/edit`
2. В правой колонке, секция «Обложка (cover_image)», выберите файл.

### Технические требования

| Изображение | Рекомендуемый размер | Форматы |
|-------------|---------------------|---------|
| Логотип     | 300×150 px, прозрачный фон | PNG, SVG, WebP |
| Обложка     | 1200×400 px | JPG, PNG, WebP |

Файлы сохраняются в `frontend/web/uploads/brands/`.

Приоритет источника логотипа: `logo_url` → `logo`.

### Что происходит если логотип отсутствует

Используется каскад замен:

1. Поле `brand.logo_url` — если заполнено, используется оно.
2. Поле `brand.logo` — если заполнено, используется оно.
3. Контроллер SiteController подтягивает первый товар бренда и использует `main_image_url`.
4. Если ничего нет — в landing-представлении рендерится placeholder с первой буквой названия бренда.

---

## Скрытие брендов-заглушек

Бренды с `name = '-'`, `name = ''` или `name IS NULL` автоматически скрываются с главной страницы (фильтрация в `SiteController::getBrands()`).

Для полного скрытия бренда из каталога — снимите галочку «Активен» в `/admin/brand/{id}/edit`.

---

## Файловая структура

```
frontend/web/uploads/
├── categories/      ← изображения категорий
├── brands/          ← логотипы и обложки брендов
└── products/        ← изображения товаров
```

## URL в админ-панели

| Раздел | URL |
|--------|-----|
| Список категорий | `/admin/category` |
| Создать категорию | `/admin/category/create` |
| Редактировать категорию | `/admin/category/{id}/edit` |
| Загрузить фото (AJAX POST) | `/admin/category/{id}/upload-image` |
| Список брендов | `/admin/brand` |
| Создать бренд | `/admin/brand/create` |
| Редактировать бренд | `/admin/brand/{id}/edit` |
| Загрузить логотип (AJAX POST) | `/admin/brand/{id}/upload-logo` |
