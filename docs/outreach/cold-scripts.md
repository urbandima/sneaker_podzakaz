# Скрипты холодного обращения (Cold Outreach Scripts)

Все скрипты ориентированы на быстрый ответ, доверие и переход к консультации. Адаптировать под реального клиента (модель, имя, интерес).

---

## Вариант 1: Instagram DM (Casual, casual trust-building)

**Профиль:** Трендсеттеры, молодежь 18–28, активны в IG  
**Тон:** Friendly, casual, не spammy  
**Цель:** Быстрый ответ, проверка интереса  
**Время ответа ≤ 5 минут**

### Скрипт 1a: По интересу к модели
```
hey 👟 заметили, что тебе нравятся {brand_name} {model}
есть свежий приход, может быть полезно 👀
все размеры есть, приехали вчера из EU

если интересно — пишу детали и примеры 🙌
```

### Скрипт 1b: По активности в комментариях
```
привет! 👋 видим твой комментарий про {model_or_brand}
мы как раз специализируемся на {brand_category}
есть {count} вариантов в наличии + возможность заказать редкие

если хочешь каталог или консультацию по размерам — пиши 🔥
```

### Скрипт 1c: По Save постов
```
hi ✌️ видим, что сохранил(а) нашу пару {model}
это действительно топ, и у нас есть вся размерная сетка

не уверен с размером — помогу выбрать по бренду 👟
интересно?
```

### Скрипт 1d: По упоминанию бренда в профиле
```
замечу, что ты фанат {brand}! 👀
у нас только что приехали limited pieces от {brand}
может быть полезно для коллекции?

если интересно, киню каталог и ответю на вопросы 🙌
```

**Follow-up 1 (если нет ответа за 24h):**
```
не видел ответ — может, сообщение потеряось 🤷
всё ещё есть, если захочешь 👟
```

**Обработка ответа:** Переход в диалог, уточнение размера + доставки.

## Вариант 2: Email (Information-dense, formal trust)

**Профиль:** Casual collectors, возраст 25–35, более консервативные  
**Тон:** Professional, но не corporate. Информативный.  
**Цель:** Подробная информация, снижение friction  
**Время отправки:** Вторник–четверг, 10:00–14:00 (по времени ресивера)

### Скрипт 2a: По интересу к эксклюзивности
```
Тема: New Release {Brand} {Model} — только на этой неделе

Привет {name},

Поделимся находкой — только что приехал лимит от {brand}:
{model_name} ({color_description})

Почему это интересно:
• ограниченное количество (не переиздается)
• оригинал, 100% проверка перед отправкой
• быстрая доставка: 5–7 дней в Беларусь, 7–10 в Россию

Цена: {price_usd} USD (+ доставка по тарифу)
Размеры в наличии: {sizes_list}

Если нужна консультация по размерам (у каждого бренда свой fit) — 
ответьте на это письмо или напишите в DM.

Гарантия: 14 дней на возврат если размер не подойдет.

В ближайшие 48ч может не быть в наличии.

Cheers,
{team_name} Sneaker Head
```

### Скрипт 2b: Реактивный (клиент искал модель)
```
Тема: Вашу модель найдем — {brand} {model}

Привет {name},

Видим, что ищете {model_name}. Хорошие новости:

✓ Модель в наличии (последняя пара в размере {size})
✓ Цена: {price_usd} USD
✓ Оригинал + проверка подлинности
✓ Доставка: {delivery_days} дней

Сложность: {size} быстро раскупывается.

Если захотите — на ответ на это письмо киню:
1. Фото распаковки перед отправкой
2. Трек доставки
3. Информацию о возврате

Тел: {phone}  
DM: {instagram_handle}  
WhatsApp: {whatsapp_link}

{team_name}
```

### Скрипт 2c: Предложение категории (не конкретной модели)
```
Тема: Качественные кроссовки {brand_category} — подобрали для вас

Привет {name},

Если вы фанат {brand_or_category}, у нас есть подборка, 
которая точно понравится:

Категория: {category_description}
В наличии: {count} моделей
Цена: {price_range_usd}

Почему мы (а не мега-маркет):
• каждая пара проверена лично
• консультация о fit и особенностях бренда
• могу рекомендовать аналоги, если нужный размер закончился

Интересно? Кину каталог на почту или напишу в DM.

Выбирайте удобный канал общения:
— Почта (ответьте на это письмо)
— Instagram: @{handle}
— WhatsApp: {link}

Жду!
{team_name}
```

**Follow-up (через 3 дня, если нет ответа):**
```
Тема: RE: Качественные кроссовки — может быть, полезнее в DM?

Привет {name},

Переслали письмо несколько дней назад — может потеряться в спаме.

Если удобнее — напишите в DM (@{handle}), ответим быстрее.

Или скажите, какую модель ищите конкретно — подберу.

Cheers,
{team_name}
```

## Вариант 3: Facebook DM (Trust-first, formal-casual hybrid)

**Профиль:** Gift hunters, родители, друзья, возраст 25–40  
**Тон:** Дружелюбный, но не casual. Trust-building.  
**Цель:** Установление доверия, подробное обсуждение  
**Время ответа: 10–15 минут**

### Скрипт 3a: По активности в группах/communities
```
Привет! 👋

Видим, что ты активен в группе {group_name} и интересуешься {interest}.
Мы специализируемся на оригинальных кроссовках и streetwear — 
может быть, полезно.

Вот что предлагаем:
✓ Оригинал (проверка каждой пары)
✓ Консультация по размерам
✓ Доставка в Беларусь/Россию за 5–10 дней
✓ Возврат на 14 дней если размер не подойдет

Если интересно обсудить конкретную модель или получить каталог —
напиши, помогу 🙌

Сайт: {website_url}
```

### Скрипт 3b: Подарок
```
Привет!

Случайно увидели, что ты близкий друг {friend_name} (или что-то в этом роде).
Может быть, помощь с подарком?

Мы специализируемся на подборе кроссовок как раз для таких случаев:
• поможем понять, что нравится человеку

• красиво упакуем
• гарантия, что подойдет (возврат 14 дней)

Если хочешь идею — расскажи:
— что за человек (возраст, стиль, интересы)
— какой бюджет
— когда нужно

Дальше я помогу подобрать идеальный вариант 👟

Интересно?
```

```

Видим твой вопрос в группе про {model_or_brand}.

```

## Универсальные правила для всех скриптов

### Адаптация под реального клиента:
- **{name}** — используй имя из профиля (если видно), иначе "привет"
- **{brand_name}**, **{model}** — конкретная модель, которую видишь в профиле
- **{price_usd}** — ориентировочная цена (без точной цены лучше "пиши, сделаем скидку")

### Tone правила:
- **Первое сообщение:** не спрашивай 3+ вопросов сразу
- **Русский/English:** дневной переезжают на English если видишь их предпочтение в профиле
- **Эмодзи:** в Instagram DM допускаются 1–2 эмодзи, в Email — без эмодзи или максимум 1 для брейка

### Конвертация скрипта в диалог:
1. **Проверка интереса** — "интересно ли вообще?"
2. **Квалификация** — "какой размер, какой бюджет"
3. **Снижение friction** — "помогу с выбором, вот гарантия"
4. **Handoff** — переход в AmoCRM/WhatsApp для финального преговора

### Когда НЕ писать:
- Если в профиле видишь, что человек (проф. аккаунт, компания, bot)
- Если профиль неактивен >6 месяцев
- Если уже писали этому человеку в течение последних 30 дней

## Метрики успеха скрипта

| Метрика | Таргет | Формула |
|---------|--------|---------|
| Reply rate | 15–20% | (replies / sent) × 100 |
| Qualification rate | 60–70% от ответов | (qualified / replied) × 100 |
| Conversion rate | 20–30% от qualified | (purchased / qualified) × 100 |
| Time-to-reply | < 2h (IG), < 6h (Email) | (earliest reply time) |

Если reply rate < 10% — аудитория слишком холодна или скрипт не цепляет. Нужна итерация.
