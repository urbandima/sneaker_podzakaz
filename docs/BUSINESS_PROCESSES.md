# Бизнес-процессы Sneakerhead E-commerce

## Общая структура

Проект состоит из 9 backend-модулей:

| Модуль | Назначение | Контроллеры |
|--------|-----------|-------------|
| catalog | Каталог товаров | CatalogController, ReviewController |
| cart | Корзина покупок | CartController |
| checkout | Оформление заказа | OrderController |
| account | Личный кабинет | AccountController, LoyaltyController, ReturnController |
| admin | Административная панель | 21 контроллер |
| coupon | Система купонов | - (только модели и сервисы) |
| loyalty | Программа лояльности | - (только модели и сервисы) |
| returns | Возвраты товаров | ReturnService |
| compare/notification | Сравнение и уведомления | - |

## 1. CATALOG — Каталог товаров

### 1.1 Просмотр каталога
**URL:** `/catalog`

**Процесс:**
1. Пагинация: 24 товара на страницу
2. Загрузка товаров через ProductRepository
3. Eager loading связей: brand, category, images, sizes
4. HTTP-кэширование (ETag, Last-Modified)
5. Денормализованные поля для скорости: brand_name, category_name

**SEO:**
- Canonical URL без trailing slash
- Meta title/description
- Schema.org разметка (JSON-LD)

### 1.2 Фильтрация товаров
**URL:** `/catalog?filter_params`

**Доступные фильтры:**
- Категория (category_id)
- Бренд (brand_id)
- Цена (min_price, max_price)
- Размер (size, через product_size)
- Характеристики (characteristic_value_id)

**Сортировка:**
- По популярности (views_count DESC)
- По цене (price ASC/DESC)
- По новизне (created_at DESC)

### 1.3 Карточка товара
**URL:** `/catalog/product/{slug}`

**Процесс:**
1. Поиск товара по slug
2. Загрузка галереи изображений
3. Расчёт диапазона цен по размерам
4. Похожие товары (тот же бренд, схожая цена)
5. Проверка "в избранном" (для авторизованных)
6. Инкремент счётчика просмотров

**Бейджи товара:**
- Скидка (hasDiscount)
- Новинка (NEW, если created_at < 14 дней)
- Хит продаж (views_count > порога)

### 1.4 Поиск товаров
**URL:** `/catalog/search?q={query}`

**Поиск по полям:**
- name
- slug
- vendor_code
- style_code

### 1.5 Избранное
**Процесс для гостей:**
- Идентификация по session_id
- Хранение в таблице product_favorite

**Процесс для авторизованных:**
- Идентификация по user_id
- Связь с Customer

**Операции:**
- Добавление (AJAX): `POST /catalog/add-favorite`
- Удаление (AJAX): `POST /catalog/remove-favorite`
- Список: `/catalog/favorites`

### 1.6 История просмотров
- Сохранение в сессии (гости) / БД (авторизованные)
- Страница: `/catalog/history`

## 2. CART — Корзина покупок

### 2.1 Структура корзины
**Таблица:** `cart`

**Поля:**
- user_id (для авторизованных)
- session_id (для гостей)
- product_id, quantity, price
- size, color (опционально)

### 2.2 Операции с корзиной

**Добавление товара:**
```
POST /cart/add
Params: product_id, quantity=1, size, color
Response: {success, message, count, total}
```

**Обновление количества:**
```
POST /cart/update
Params: id, quantity (1-99)
```

**Удаление позиции:**
```
POST /cart/remove
Params: id
```

**Очистка корзины:**
```
POST /cart/clear
```

**Получение счётчика:**
```
GET /cart/count
Response: {count}
```

### 2.3 Слияние корзин
**Триггер:** Авторизация пользователя

**Процесс:**
1. Проверка гостевой корзины по session_id
2. Слияние с пользовательской корзиной
3. Приоритет: максимальное количество для одинаковых товаров
4. Очистка гостевой корзины

## 3. CHECKOUT — Оформление заказа

### 3.1 Создание заказа
**URL:** `POST /checkout/order/create`

**Поля запроса:**
- name, phone, email (обязательные)
- country, delivery_method (обязательные)
- address (обязательно, кроме самовывоза)
- comment (опционально)
- customer_id (для авторизованных)
- use_saved_address (boolean)
- save_to_profile (boolean)

**Процесс:**
1. Валидация обязательных полей
2. Получение товаров из корзины
3. Расчёт стоимости доставки (ShippingService)
4. Применение купона (если указан)
5. Списание баллов лояльности (если указаны)
6. Транзакционное создание:
   - Создание Order
   - Создание OrderItem для каждого товара
   - Создание OrderHistory
   - Применение купона (увеличение счётчика)
   - Списание баллов
   - Очистка корзины
7. Отправка email (клиент + менеджер)

**Генерация:**
- order_number: `WEB-{YYYYMMDD}-{RANDOM6}`
- token: 32 символа (для доступа без авторизации)

### 3.2 Расчёт доставки
**Сервис:** ShippingService

**Методы доставки:**
- courier_minsk — курьер по Минску (зоны)
- pickup_minsk — самовывоз (бесплатно)
- europochta — Европочта
- belpochta — Белпочта
- sdek — СДЭК

**Расчёт:**
- Базовая стоимость + зоны (курьер)
- Бесплатно от пороговой суммы
- Учёт веса (costPerKg)

### 3.3 Применение купона
**Сервис:** CouponService

**Валидация:**
- Существование купона
- Срок действия
- Лимит использований
- Минимальная сумма заказа
- Применимость к товарам/категориям

**Типы скидок:**
- fixed — фиксированная сумма
- percent — процент от суммы
- free_shipping — бесплатная доставка

**Расчёт:**
```php
if (type == 'fixed') discount = min(value, orderAmount)
if (type == 'percent') discount = orderAmount * value / 100
```

### 3.4 Списание баллов лояльности
**Сервис:** LoyaltyService

**Правила:**
- Минимум для списания: 100 баллов
- Максимум: 50% от суммы заказа
- Курс: 1 балл = 0.01 BYN

**Процесс:**
1. Проверка баланса клиента
2. Валидация запрошенного количества
3. Расчёт скидки: points × pointValue
4. Запись операции (type: 'redeem')
5. Обновление баланса

### 3.5 Страница успеха
**URL:** `/checkout/success?token={token}`

**Элементы:**
- Подтверждение заказа
- Номер заказа
- Рекомендованные товары (upsell)
- Ссылка на каталог

### 3.6 Загрузка подтверждения оплаты
**URL:** `POST /checkout/order/upload-payment`

**Безопасность:**
- Rate limiting: 5 попыток за 15 минут
- Валидация MIME-типа (image/*, application/pdf)
- Проверка magic bytes
- Хранение вне web root
- Ограничение размера файла

## 4. ACCOUNT — Личный кабинет

### 4.1 Авторизация покупателя
**Механизм:** Сессионная авторизация (customer_id в сессии)

**Процесс:**
- Вход: проверка email/пароль, создание сессии
- Выход: очистка сессии
- Восстановление пароля: email с токеном

### 4.2 Управление профилем
**URL:** `/account/profile`

**Поля профиля:**
- ФИО (last_name, first_name, middle_name)
- Телефон, email
- Дата рождения, пол
- Паспортные данные (для таможни)
  - Серия, номер, дата выдачи
  - ИНН

**Адрес доставки по умолчанию:**
- Страна, город, индекс
- Полный адрес

**Настройки уведомлений:**
- Подписка на новости
- Подписка на акции

### 4.3 История заказов
**URL:** `/account/orders`

**Список заказов:**
- Номер заказа
- Дата создания
- Статус
- Сумма

**Детальная страница заказа:** `/account/order-view?id={id}`

**Элементы:**
- Состав заказа (товары, размеры, цвета)
- Информация о доставке
- Трек-номер (если отправлен)
- Таймлайн статусов:
  1. Заказ создан
  2. В обработке
  3. Отправлен
  4. Доставлен

**Статусы заказа:**
- created — создан
- processing — в обработке
- shipped — отправлен
- delivered — доставлен
- completed — завершён
- cancelled — отменён

### 4.4 Программа лояльности
**URL:** `/account/loyalty`

**Элементы:**
- Текущий баланс баллов
- Уровень клиента (Bronze/Silver/Gold/Platinum)
- История операций (начисления/списания)
- Условия программы

### 4.5 Возвраты
**URL:** `/account/returns`

**Создание заявки:**
- Выбор заказа
- Выбор товаров для возврата
- Указание причины
- Добавление комментария
- Адрес для забора

**Статусы заявки:**
- pending — ожидает рассмотрения
- approved — одобрена
- rejected — отклонена
- completed — завершена (возврат средств)

## 5. COUPON — Система купонов

### 5.1 Структура купона
**Таблица:** `coupon`

**Поля:**
- code — код купона (уникальный, верхний регистр)
- name — название
- type — тип (fixed/percent/free_shipping)
- value — значение скидки
- min_order_amount — минимальная сумма заказа
- max_uses — максимум использований
- max_uses_per_user — максимум на пользователя
- start_date, end_date — срок действия
- is_active — активность
- applicable_products — JSON массив ID товаров
- applicable_categories — JSON массив ID категорий

### 5.2 Жизненный цикл купона

**Создание (админ):**
- Генерация случайного кода (actionGenerateCode)
- Или ручной ввод
- Настройка условий применения

**Применение (клиент):**
- Ввод кода на checkout
- Валидация через CouponService
- Расчёт скидки
- Привязка к заказу (coupon_id, coupon_code)

**Использование:**
- Увеличение current_uses при завершении заказа
- Запись в coupon_usage (кто, когда, какой заказ, сумма скидки)

**Деактивация:**
- Нельзя удалить использованный купон
- Только деактивация (is_active = false)

## 6. LOYALTY — Программа лояльности

### 6.1 Уровни программы
**Таблица:** `loyalty_program`

| Уровень | Мин. баллов | Множитель |
|---------|-------------|-----------|
| Bronze | 0 | 1.0x |
| Silver | 500 | 1.2x |
| Gold | 2000 | 1.3x |
| Platinum | 5000 | 1.5x |

### 6.2 Начисление баллов
**Правила:**
- Базово: 10 баллов за 1 BYN
- Множитель уровня
- Начисление при завершении заказа

**Пример:**
```
Заказ на 300 BYN, уровень Gold (1.3x)
Баллы = 300 × 10 × 1.3 = 3900 баллов
```

### 6.3 Списание баллов
**Правила:**
- Минимум: 100 баллов
- Максимум: 50% от суммы заказа
- Курс: 1 балл = 0.01 BYN

**Пример:**
```
Заказ на 500 BYN, баланс 3000 баллов
Макс списание = min(3000, 500×50/0.01) = 2500 баллов
Скидка = 2500 × 0.01 = 25 BYN
```

### 6.4 История операций
**Таблица:** `loyalty_points`

**Поля:**
- customer_id
- order_id (если связано)
- type — 'earn' или 'redeem'
- points — количество
- description
- created_at

## 7. RETURNS — Возвраты товаров

### 7.1 Политика возврата
**Таблица:** `return_policy`

**Условия:**
- Срок: 14 дней с момента получения
- Состояние: не ношен, бирки/упаковка сохранены
- Исключения: персонализированные товары, нижнее бельё

### 7.2 Создание заявки
**Процесс:**
1. Выбор заказа (из истории)
2. Выбор товаров для возврата (items_json)
3. Указание причины (reason)
4. Комментарий (comment)
5. Адрес для забора (pickup_address)

**Валидация:**
- Заказ должен принадлежать клиенту
- Срок возврата не истёк
- Товары соответствуют политике

### 7.3 Обработка заявки (админ)
**Статусы:**
- pending → approved/rejected
- approved → completed (после получения товара)

**Одобрение:**
- Проверка соответствия политике
- Расчёт суммы возврата

**Отклонение:**
- Указание причины отклонения

**Завершение:**
- Получение товара
- Возврат средств (refund_method: original)
- Обновление остатков

### 7.4 Возврат средств
**Способ:** На исходный способ оплаты
**Сумма:** Фактическая стоимость возвращённых товаров
**Уведомление:** Email клиенту

## 9. Ключевые бизнес-правила

### 9.1 Корзина
- Максимум 99 штук одного товара
- Автоматическое удаление неактивных товаров
- Слияние при авторизации (приоритет: макс количество)

### 9.2 Заказ
- Обязательные поля: имя, телефон, доставка
- Адрес не требуется только для самовывоза
- Уникальный токен для доступа без авторизации
- Email уведомления клиенту и менеджеру

### 9.3 Купоны
- Код в верхнем регистре
- Нельзя удалить использованный купон
- Применимость: все товары / категории / конкретные товары

### 9.4 Баллы лояльности
- Начисление при завершении заказа
- Списание мин 100 баллов
- Максимум 50% от суммы заказа
- Курс фиксирован: 1 балл = 0.01 BYN

### 9.5 Возвраты
- Срок: 14 дней
- Товар не ношен, бирки/упаковка сохранены
- Возврат на исходный способ оплаты
- Исключения: персонализированные товары, нижнее бельё

### 9.6 Ценообразование
- Диапазон цен по размерам (price_byn в product_size)
- Если размер не выбран — показывается диапазон
- При выборе размера — конкретная цена

## Схема потока данных

```
Клиент → Каталог → Корзина → Checkout → Заказ
                           ↓
                    Купон/Баллы → Скидка
                           ↓
                    Оплата → Успех
                           ↓
                    Email уведомление
                           ↓
                    Админ → Обработка → Доставка
                           ↓
                    Возврат (при необходимости)
```
