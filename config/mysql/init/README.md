# config/mysql/init

Смонтировано в контейнере `db` как `/docker-entrypoint-initdb.d` (см. `config/docker/docker-compose.yml`).

MySQL выполняет файлы `*.sql`, `*.sql.gz` и `*.sh` из этой директории **в алфавитном порядке**,
и **только при первом старте** контейнера (когда volume `db-data` ещё пуст).

Что сюда класть:
- `.sql` дампы для начального наполнения схемы/сидов (если нужны при первом старте контейнера).
- Если такие дампы не нужны — директория может оставаться пустой: схема создаётся штатно через
  `docker compose exec app php yii migrate` после старта контейнеров.

Директория была пустой и не отслеживалась в git (git не хранит пустые каталоги) — этот README
существует, чтобы каталог попал в репозиторий и его назначение было задокументировано.
